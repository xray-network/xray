# Third-party licenses

Everything in this repository is licensed under the [MIT License](LICENSE), except third-party code
and assets.

Each third-party piece keeps its owner's license in its own folder, as `LICENSE`. Where a folder also
holds XRAY/Network files, the owner's license is named `LICENSE-<OWNER>` instead (for example
`mini-app-graph-services/ogmios/LICENSE-CARDANO-SOLUTIONS`). Captured upstream evidence under
`.agents/spectre/providers/` keeps the license files it was captured with.

Dependencies installed by npm, Docker, or vcpkg are not stored in this repository and are licensed by
their own packages.
