# xray-mini-app-cardano-assets

The mini app uses the direct, versioned XRAY bridge namespaces. Platform status and preferences come
from `platformV1`, while Cardano account data and explorer settings come from `cardanoV1`; calls do
not require a handshake.

## Wiki

The independent Rspress wiki lives in [`wiki/`](wiki/README.md). Run its development,
build, and deployment commands from that directory.
